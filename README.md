# R-data-analysis-sample
***Evaluation of a Cook County State’s Attorney’s Office recidivism program: cleaned and merged administrative datasets, engineered charge and re-arrest indicators, checked baseline balance, and estimated treatment effects.***

I was given simulated administrative data from the Cook County State’s Attorney’s Office to evaluate a one-year recidivism-reduction program in Chicago with randomized assignment to treatment and control. Using R, I:

1. Recoded race/ethnicity and summarized sample composition

2. Merged arrests with crime records and restricted to Chicago arrests

3. Created flexible charge indicators (e.g., homicide, weapons)

4. Reconstructed and validated the post-assignment re-arrest outcome

5. Tested baseline balance and produced a partner-ready visualization

6. Estimated the relationship between treatment assignment and re-arrest using statistical models

The datasets are in the repository and the full analysis exercise can be accessed through the Rmd file.

(Note: Data were generated/manipulated for assessment purposes and are not intended for real-world inference.)
